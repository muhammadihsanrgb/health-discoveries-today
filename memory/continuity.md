# Prosedur Sesi Baru

Setiap kali memulai sesi, lakukan checklist berikut:

1. **Baca current-state.json**: Periksa tugas mana yang in-progress.
2. **Review Kepatuhan**: Jika baru saja menjalankan revisi, cek file audit untuk memastikan tidak ada revisi yang terlewat.
3. **Sinkronisasi**: Pastikan git remote/auth masih valid.
4. **Resep Brainstorming**: Gunakan prompt induk untuk konteks tambahan jika ingin berdiskusi.

**Tujuan:** Menjamin kesinambungan kerja tanpa kehilangan konteks.
